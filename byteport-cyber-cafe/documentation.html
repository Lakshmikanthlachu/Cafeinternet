Byteport · v1.1.0

Template documentation

Multipurpose HTML template for cyber cafés and internet centers. Tailwind CSS 3, vanilla JS, dark/light themes, RTL, self-hosted fonts, no build step required to use.

1. Pages

  • index.html — Home 1, general cyber café (parallax hero, live floor map, session calculator, pinned photo tour)
  • index-2.html — Home 2, gaming arena / eSports lounge (RGB keyboard, pinned zones, ladder)
  • about.html, services.html, rates.html (pricing)
  • service-details.html (Printing) plus one page per service: service-browsing, -scan, -forms, -gaming, -pods, -lamination, -typing, -tickets
  • blog.html — category chips with counts, search with clear button, tag filters, pagination. Deep links: ?cat=security, ?tag=privacy, ?q=wifi
  • One page per article: blog-details.html, blog-print-resume.html, blog-arena-240hz.html, blog-exam-form-guide.html, blog-symmetric-fiber.html, blog-video-interview-pod.html, blog-console-corner.html, blog-spot-phishing.html, blog-freelance-day-pass.html (blog-details.html is the first article)
  • contact.html (map, validated booking form), 404.html, coming-soon.html

2. Folder structure

  • assets/css/style.css — compiled CSS; assets/css/tailwind.input.css — source (fonts, tokens, components)
  • assets/fonts/ — self-hosted WOFF2 fonts (Chakra Petch, Manrope, JetBrains Mono, Cairo for Arabic)
  • assets/js/main.js — all interactions; each feature is switched on by a data-* attribute
  • assets/og-image.png — social share image (same logo as the header, footer and favicon)
  • sitemap.xml, robots.txt, vercel.json, README.md

3. Editing styles

  • Install Node.js 18+, then npm install
  • npm run watch while editing, or npm run build once
  • Brand colours live in tailwind.config.js (signal, pulse, volt, ink)
  • After changing CSS or JS, raise the ?v= number on the style.css and main.js links so visitors get the new files

4. Deploying

npm run build:public copies the site into public/. On Vercel the included vercel.json runs the build and serves public/; the 404 page is picked up automatically. Any static host works too — upload the HTML files plus assets/.

5. Dark mode & RTL

The header buttons toggle the dark class and dir="rtl" on <html> and remember the choice (bp-theme, bp-dir in localStorage). For an Arabic or Hebrew site set <html lang="ar" dir="rtl"> directly — spacing uses logical properties and the Cairo font is included.

6. Forms

Every form shows inline messages under the field: required fields, letters-only names, email format, mobile numbers (digits with an optional leading +, at least 9 digits, checked while typing and on submit), no past dates and booking times only inside opening hours (Open daily · 8:00 AM – 2:00 AM). Rules are attributes: required, data-name, data-phone, data-future-date, data-time-slot, pattern + data-pattern-msg. Every <select class="field"> becomes a styled, keyboard-friendly list automatically. Forms with data-fake-form show a success popup; remove it and set action/method to connect a backend.

Map: the contact page uses a standard Google Maps embed. Change the coordinates 40.7080,-74.0040 in the iframe src and in the “Get directions” / “Open in Google Maps” links (or paste the embed code from Google Maps → Share → Embed a map).

7. Interactive features

  • data-reveal, data-parallax, data-depth — scroll reveal and parallax (all motion is off for “reduce motion” users)
  • data-pin — pinned horizontal scroller (switches to a swipe row on short landscape screens)
  • data-paginate, data-filter-group, data-search — filters, search and pagination
  • data-share, data-reply, data-floor, data-calc, data-print-calc, data-countdown

Keyboard: dropdowns open with arrow keys and close with Escape; the mobile menu and popups keep focus inside until closed.

8. SEO

Unique titles and descriptions, canonical URLs, Open Graph and Twitter tags, one H1 per page, landmarks, JSON-LD (InternetCafe, BlogPosting), sitemap.xml and robots.txt. Replace https://byteport.example/ with your domain.

9. Photos

All photos are from Unsplash (Unsplash License). Each photo is used in one place only (a blog card shows the same cover as its own article). They load from the Unsplash CDN up to 3840 px wide; run npm run localize-images to bundle them. Check your marketplace’s rules on bundling stock photos.
